# Hephaestus Engine — Developer Docs

Welcome! These developer-facing docs are for engineers who work on the Hephaestus Engine source code (internal engine contributors). They cover how to set up a local environment, the high-level architecture, coding standards, testing and CI, release processes, and contribution guidelines.

If you're here because you are writing games on top of Hephaestus, see the public user docs instead; these docs assume familiarity with basic engine concepts and focus on building, changing, and extending engine internals.

Contents
- setup.md — local development environment and build steps
- architecture.md — high-level architecture and core subsystems
- coding-guidelines.md — style, API stability, and PR expectations
- testing-and-ci.md — automated tests, profiling, and CI flow
- contributing.md — process for issues, branches, and pull requests
- releasing.md — tagging, changelogs, and binary artifacts

Quick links
- Repo: https://github.com/Olympus-Game-Studios/Hephaestus-Engine
- Issue tracker: https://github.com/Olympus-Game-Studios/Hephaestus-Engine/issues

How to use these docs
- Read setup.md first to get a working dev environment.
- Use architecture.md when planning changes or new subsystems.
- Check coding-guidelines.md before writing code or opening a PR.
- Run tests locally and ensure CI passes per testing-and-ci.md.
- Follow contributing.md for PRs and reviews.
