
# Hephaestus Engine — Documentation (Public)

Welcome! This site is the documentation hub for game developers building games with the Hephaestus Engine. It is not a mirror of the engine source — it provides the information you need to create, script, and ship games using the engine and editor binaries provided by the project.

**Who this is for**
- Game developers creating titles with Hephaestus.
- Technical designers and tools engineers building game content and scripts.
- Mod authors and content integrators who consume runtime APIs and editor tooling.

Important note: the engine source code is not included in this public documentation. If you need engine internals or source access, contact the project maintainers for appropriate access or binary SDKs.

**Start here**
- [getting-started.md](Hephaestus-Engine/getting-started.md) — Install the editor, create your first project, and run the sample scene.
- [editor-overview.md](Hephaestus-Engine/editor-overview.md) — Learn the editor layout, project structure, and common authoring workflows.
- [scripting-overview.md](Hephaestus-Engine/scripting-overview.md) — Scripting model, lifecycle, and common patterns for gameplay systems.
- [scripting-api.md](Hephaestus-Engine/scripting-api.md) — API reference and example snippets for common tasks (entity access, events, serialization).
- [editor-controls.md](Hephaestus-Engine/editor-controls.md) — Input mappings, editor shortcuts, and control reference.

Key workflows covered
- Project setup and templates — how to structure your game's project to work with the editor.
- Asset pipeline basics — importing, processing and referencing textures, models, audio, and other assets.
- Scripting and live-reload — author gameplay logic and iterate quickly using the scripting system.
- Packaging and builds — how to prepare game builds using the provided tooling (see `getting-started.md` for links and commands).


Read-only site
- This public documentation is intended for game developers consuming the editor and runtime. The public site is read-only — users who only have access to the public pages cannot directly edit or submit changes to these documents.
- To request a documentation change, correction, or to ask about SDK/binary access, contact the project maintainers or the organisation's documentation team. Maintainers will accept and apply changes through the internal contribution process.

Support & downloads
- For questions about the engine, downloads, or developer access, contact the maintainers. The public site does not provide engine source; it documents how to use the editor and runtime binaries.
